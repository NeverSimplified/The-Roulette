# The Roulette
This project was made to experiment with a framework coding-style. Uses a custom made framework inspired by @unix_system on Roblox. (Thank you for teaching me this)

## How does it work?
Both server and client have bootloaders that load Services within its file organisation. All being ran under a single script environment for ease of access when requiring modules.

## What will happen to this game?
This game is discontinued. It was a project that was made in a week or two. It now serves a purpose of showcasing my ability to adapt to coding styles and different methods when it comes to coding roblox experiences.
